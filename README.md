# FeishuAgent
此为广州大学: 好运连连队伍项目代码
初上传日期为20260508 16:35

本项目是一个深度集成飞书生态的智能招聘助手，利用大语言模型实现简历智能解析与岗位语义匹配，输出0-100分量化评分并依据可配置阈值自动决策——高分简历进入面试预约流程、低分简历自动生成并发送个性化拒信（测试准确率达93.3%）；
面试协调环节，HR在飞书界面一键确认时间后，系统自动调用飞书日历API创建会议，并在面试前通过飞书消息提醒HR及面试官、通过邮件提醒候选人，实现双渠道自动化通知，将面试协调从多轮沟通压缩为一次确认。
项目基于Python开发，集成飞书开放平台API与Coze工作流，当前已完成简历解析匹配、自动拒信、会议预约及双渠道提醒四大核心功能，AI面试与人才库动态重检作为下一阶段迭代方向。
